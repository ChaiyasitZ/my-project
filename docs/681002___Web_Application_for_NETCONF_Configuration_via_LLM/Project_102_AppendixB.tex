\section{การติดตั้งและใช้งาน Ollama}
\hspace*{1.3em}
Ollama เป็น platform สำหรับรัน Large Language Models (LLMs) แบบ local บนเครื่อง PC หรือ Mac รองรับ models หลายตัว เช่น llama, codellama, mistral, gemma\vspace{0.5em}
